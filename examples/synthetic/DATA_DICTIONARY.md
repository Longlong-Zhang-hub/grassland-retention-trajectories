# Synthetic example fields

`provenance` is always `SYNTHETIC_NOT_STUDY_DATA`. `case_id` is a decimal uint64 string. Open with a text-preserving CSV reader. `year` and all event clocks are invented calendar years. `state` is an invented class code: 1 for initial source, 3 for target and 2 for another observed class. `NA` denotes an unavailable state, clock or outcome. Boolean indicators use `1` and `0` when defined.

`onset_year` is the exact first transition year. `first_exit` starts a two-year non-target run, `confirmation` is its second year, and `censor` is the last usable year for an unconfirmed exit. `return_year` is the first observed target year strictly after confirmation. `H3_eligible` and `H5_eligible` indicate complete follow-up after confirmation. Their `return` columns are defined only for eligible cases. `reexit_eligible` requires observation through return year plus four, and `reexit` records a two-year exit starting within the next three years. `exit_status` records the event or censoring outcome.

The deterministic fixture is generated by `example_rows()` in `code/demo_synthetic.py`. The demonstration checks it against the packaged file and writes the generated cases and event outputs. The expected files serve as a local regression reference.
