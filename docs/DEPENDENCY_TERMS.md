# Runtime dependencies

The synthetic test and demo use Python standard library imports only. The frozen display runner uses Matplotlib Agg with its installed NumPy dependency. The archive carries no package binaries or copied dependency code. Version records describe the environment tested on Windows. Packaging by others should account for the installed distribution notices.

- Python PSF terms. https://docs.python.org/3.10/license.html
- Matplotlib distribution terms. https://matplotlib.org/stable/project/license.html
- NumPy distribution terms. https://numpy.org/doc/stable/license.html
