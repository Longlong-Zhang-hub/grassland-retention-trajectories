# Data products referenced by the study

The code candidate carries no provider datasets. The archived CLCD reference is v1.0.3. The public GLC record below identifies v1, while the study archive is labeled v2 and its exact binding is pending. The historical TerraClimate inputs are kept separate from v1.1. Consult the study documentation for exact RZSM, PML and other archived products. Published access terms and author redistribution permissions are separate.
